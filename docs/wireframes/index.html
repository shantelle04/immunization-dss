1. Login (FR-01, NFR-03)

Immunization DSS Log in No self-registration: accounts are created by the system administrator. After repeated failed attempts the account is locked for a period.
Notes. Generic error message ("username or password incorrect") so accounts cannot be probed. After login the user lands on the dashboard for their role and facility.
